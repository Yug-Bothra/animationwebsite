🎬 Animation Website (Frontend)

Live Demo: https://animationwebsite-kappa.vercel.app/

A modern React + Vite powered animation portfolio website with 3D models, smooth UI animations, and multi-section pages.

🚀 Tech Stack

React (Vite) — Ultra-fast frontend setup

Tailwind CSS — Utility-first styling

Three.js / 3D Models (.glb) — Interactive 3D assets

Framer Motion — UI animations

ESLint + PostCSS — Code quality and tooling

🛠️ Setup & Run Locally
# Clone the repo
git clone https://github.com/Yug-Bothra/animationwebsite.git

# Go to frontend folder
cd animationwebsite/frontend

# Install dependencies
npm install

# Start the server
npm run dev


Visit in browser:

http://localhost:5173
